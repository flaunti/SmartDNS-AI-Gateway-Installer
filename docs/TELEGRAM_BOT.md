# Управление доменами через Telegram

Дополнительный бот для уже установленного SmartDNS AI Gateway. Он управляет
`/etc/smartdns/domains.txt` и применяет список через существующий `smartdns-rebuild`.
Переустанавливать DNS-сервер не требуется. Порты и настройки клиентов не меняются.

## Установка

Создайте отдельного бота через @BotFather. На DNS-сервере от root выполните:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/flaunti/SmartDNS-AI-Gateway-Installer/main/install-telegram-bot.sh)
```

Установщик запросит токен скрытым вводом и числовые Telegram ID администраторов.
Токен не передавайте в переписке и не записывайте в командную строку. Несколько ID
разделяются запятыми. После установки откройте бота и отправьте `/start`.
Ветку или commit для проверки PR можно выбрать через `--ref REF`; URL самого
установщика должен указывать на тот же REF.

Обновление выполняется той же командой; существующий токен сохраняется.
Для смены токена или администраторов добавьте `--configure`.
Повторно запускать основной `install-smartdns.sh` для установки бота не нужно:
он может перезаписать список доменов.

## Меню и команды

- **Домены** / `/list`: список с перелистыванием, по 10 доменов.
- **Поиск** / `/search example`: поиск по списку.
- **Добавить** / `/add example.com another.org`: добавить до 50 доменов.
- **Удалить** / `/remove example.com`: удалить указанные записи.
- **Сервисы** / `/status`: состояния Unbound, dnsdist, nginx и число доменов.
- **Откатить изменение** / `/undo`: вернуть список из последней резервной копии.
- `/cancel`: выйти из ввода доменов; кнопка «Отмена» отменяет конкретное подтверждение.

После «Добавить» или «Удалить» можно прислать домены сообщением, по одному на строку.
URL и IP-адреса не принимаются. `*.example.com` нормализуется в `example.com`:
поддомены сервер уже включает автоматически. Кириллические имена сохраняются
в IDNA-форме. Удаление `sub.example.com` не исключает его из маршрутизации,
если в списке остаётся родительский `example.com`.

Изменение применяется только по кнопке **«Применить»**. Подтверждение одноразовое,
привязано к администратору и личному чату, действует 10 минут. Если список
изменился после показа подтверждения, бот откажется применять старую операцию.
Удаление последнего домена запрещено. Лимит полного списка — 5000 записей.

Операция `/undo` сама сохраняет резервную копию текущего списка: повторный откат
позволяет вернуть отменённое состояние. Сохраняются последние 20 копий.
Комментарии и порядок списка после успешного изменения нормализуются; точные
исходные файлы остаются в резервной копии.

## Применение и восстановление

Перед записью сохраняются исходные файлы списка, nginx stream и dnsdist с их
правами/владельцами. Затем вызывается штатный `smartdns-rebuild` и проверяется
запуск nginx/dnsdist. Текущий rebuild перезапускает сервисы, поэтому при
применении возможен краткий обрыв соединений через шлюз.

При ошибке или превышении времени восстанавливаются точные исходные файлы,
проверяется их синтаксис и перезапускаются сервисы. Если не удался и откат,
бот сообщает критическую ошибку; требуется проверка сервера. Журнал незавершённой
операции позволяет восстановить файлы при следующем вызове управляющего helper
после аварийного завершения процесса. Это не резервное копирование всего VPS.

Изменения бота сериализуются блокировкой. Ручное редактирование файла и вызов
rebuild извне не используют эту блокировку: не выполняйте их одновременно с
применением через бота. Проверка версии обнаруживает изменения до начала записи.

## Доступ и службы

Только перечисленные Telegram ID, только личные чаты. Бот работает от
`smartdns-bot`; root-owned helper через sudo разрешает фиксированные операции
со списком, проверкой сервисов и восстановлением. Командной оболочки в Telegram
нет. Файлы бота и sudo helper недоступны этому пользователю для записи.

Токен: `/etc/smartdns-telegram-bot/bot.env`, root:root 0600.
Состояние и одноразовые подтверждения: `/var/lib/smartdns-bot/state.sqlite3`.
Копии и журнал изменений: `/var/lib/smartdns-bot-backups/`.
Бот использует long polling, входящий HTTP-порт не открывается. Токен с активным
webhook автоматически не перенастраивается: используйте отдельного бота.

```bash
systemctl status smartdns-telegram-bot
journalctl -u smartdns-telegram-bot -n 50 --no-pager
systemctl restart smartdns-telegram-bot
```

Бот меняет серверный список. Локальный список доменов Windows App Bridge
автоматически не синхронизируется. Для нового домена в Windows-клиенте его
пока нужно добавить и там.

API: https://core.telegram.org/bots/api#getupdates
